Privacy policy

Last updated: November 18, 2026.

Forge Doorbell is a personal-use tool. Its only users are its owner, Andras Hangyal, and his own Google accounts.

What it accesses

It uses the Gmail permission gmail.send only, to send notification emails from the owner's account to the owner's own addresses. It cannot read, search, modify or delete any email.

What it stores

An OAuth token, kept only on the owner's own computer, so it can send those notifications. No Google user data is collected, sold, shared or sent to anyone else.

Google API Services

Forge Doorbell's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
